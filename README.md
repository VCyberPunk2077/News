# News

Android-приложение для чтения новостей по пользовательским подпискам. Пользователь добавляет интересующие темы, выбирает подписки для отображения в ленте и получает актуальные статьи из **NewsAPI**. Загруженные материалы сохраняются локально, поэтому список статей остаётся доступен после закрытия приложения.

## Возможности

* Добавление и удаление тематических подписок.
* Загрузка новостей по каждой подписке через NewsAPI.
* Выбор подписок, статьи по которым нужно показывать в общей ленте.
* Ручное обновление новостей.
* Очистка сохранённых статей для выбранных подписок.
* Выбор языка поиска: английский, русский, французский и немецкий.
* Настройка периода фонового обновления: от 15 минут до 24 часов.
* Ограничение фоновой синхронизации Wi-Fi-сетями.
* Уведомления о новых статьях.
* Открытие полной статьи во внешнем браузере.
* Отправка ссылки на статью через системное меню «Поделиться».
* Локальное кэширование подписок и статей.

## Фоновое обновление

После запуска приложения `AppStartupManager` начинает наблюдать за настройками обновления. При изменении языка, интервала или параметра «только Wi-Fi» создаётся новая уникальная периодическая задача `WorkManager`.

`RefreshDataWorker`:

1. Получает текущие настройки.
2. Обновляет статьи по всем подпискам.
3. Проверяет, появились ли новые записи в локальной базе.
4. Показывает уведомление, если уведомления включены и были найдены новые статьи.

Для работы по Wi-Fi используется ограничение `NetworkType.UNMETERED`, в остальных случаях — `NetworkType.CONNECTED`.

## Настройка API-ключа

Для получения новостей необходим ключ NewsAPI.

1. Зарегистрируйтесь на [NewsAPI](https://newsapi.org/) и создайте API key.
2. Не добавляйте ключ в исходный код или репозиторий.
3. Передайте ключ в `local.properties` под именем `NEWS_API_KEY`.

```properties
NEWS_API_KEY=your_newsapi_key
```

## Запуск

1. Клонируйте или скачайте репозиторий проекта.
2. Откройте проект в Android Studio.
3. Добавьте ключ NewsAPI в локальную конфигурацию проекта.
4. Синхронизируйте Gradle.
5. Запустите приложение на эмуляторе или физическом устройстве.

> Для уведомлений на Android 13 и выше приложение запрашивает разрешение `POST_NOTIFICATIONS` при включении соответствующей настройки.

## Экранные сценарии

### Подписки

* Введите тему в поле «Что интересует?».
* Нажмите «Добавить подписку».
* Выберите одну или несколько подписок в горизонтальном списке.
* Просматривайте статьи, относящиеся к выбранным темам.
* Используйте кнопки в верхней панели для ручного обновления, очистки статей и перехода к настройкам.

### Настройки

* Выберите язык запроса к NewsAPI.
* Укажите период фонового обновления.
* Включите или выключите уведомления.
* Ограничьте фоновое обновление только Wi-Fi-сетью.
